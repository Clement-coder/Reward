# Nova Chase Rewards

Build “Nova Chase” – Premium Prize Challenge Platform





Create a premium, game-inspired web application called Nova Chase. The design should feel luxurious, futuristic, and exciting, using a white, red, and black color palette. The experience should be filled with smooth animations, cinematic transitions, glowing effects, and premium micro-interactions, giving users the feeling of participating in an exclusive luxury prize campaign.
